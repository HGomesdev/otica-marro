# Ótica Marrô | Curadoria Escultural

Este é o site institucional da **Ótica Marrô**, localizada em Buritama - SP. O projeto foi desenvolvido com foco em design minimalista e experiência de luxo, refletindo a curadoria pessoal de armações e o serviço de visagismo da boutique.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estrutura semântica.
* **CSS3:** Estilização avançada, animações de scroll e design responsivo (Mobile First).
* **JavaScript (Vanilla):** Lógica de navegação, menu mobile e efeitos de revelação (Intersection Observer).

## ✨ Funcionalidades
- [x] Design Responsivo (Adaptado para Celular e Desktop).
- [x] Barra de marcas animada (Ticker).
- [x] Botão flutuante de WhatsApp direto para agendamento.
- [x] Mapa interativo com localização real.
- [x] Seção de avaliações reais do Google.
